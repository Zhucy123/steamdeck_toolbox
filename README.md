# SteamDeck 工具箱

一个专为 SteamDeck 设计的全方位系统管理工具，集成了系统优化、软件安装、网络工具等26项实用功能。无论您是新手还是高级用户，都能从中找到需要的工具。

## 主要功能
- 🛠️ **系统优化**：国内源配置、虚拟内存调整、磁盘修复
- 📦 **软件管理**：一键安装QQ、微信、WPS、浏览器等常用应用
- 🌐 **网络工具**：UU/迅游加速器、ToMoon网络优化
- 🔄 **双系统支持**：引导修复、Windows-SteamOS互通盘配置
- 🎮 **游戏增强**：摇杆校准、插件商店管理
- 📁 **便捷工具**：应用更新卸载、hosts缓存清理

## 一键安装
konsole中输入下方脚本一键安装
curl -L https://gitee.com/Zhucy2100/steamdeck_toolbox/raw/master/steamdeck_toolbox.sh -o steamdeck_toolbox.sh && chmod +x steamdeck_toolbox.sh && konsole --hold -e ./steamdeck_toolbox.sh
