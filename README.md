# SteamDeck 工具箱

[English](./README_EN.md)

一个专为 Steam Deck 打造的一站式系统管理与增强工具，集成系统优化、引导管理、软件安装、网络加速、双系统支持、游戏增强等 40 余项实用功能，全面覆盖日常使用与进阶调校需求。

> **版本：v2.0.1** | 更新日期：2026-11-03
> 制作人：Zhucy

## 🚀 一键安装

在 Konsole 中执行以下命令即可安装：

```bash
curl -L decktool.pages.dev/i | sh
```
（如果这个失效就用下面的）
```bash
curl -L https://gitee.com/Zhucy2100/steamdeck_toolbox/raw/master/install_gui.sh | sh
```

2026-11-02（v2.0.0）
【问题修复】
- 修复「更新全部应用」进度条后面出现乱码的一串字符（`^[[20;68R^[[20;68R^[[20;77R`）
  - 根因：flatpak 画进度条前先发 `ESC[6n` 问终端「光标在哪」，VTE 按协议把 `ESC[行;列R` 写回终端的输入方向；而终端默认开着 ECHO，内核就把这串应答回显到屏幕上，于是成了看得见的乱码
  - 修法：给 `flatpak update` 加上 `--noninteractive`，让它走纯文本逐行输出、不画 ANSI 进度条。没有进度条就不会发光标查询，从源头消除乱码
  - 实测对比（同一台机器、同样无更新的状态）：默认 → 转义符 31 个，含 ANSI 加粗与光标控制；加该参数后 → 转义符 0 个
  - 为什么不用「关掉终端 ECHO」的办法：那只是让应答不显示，字节仍留在输入缓冲区里，后续 `read` 会读到残留（实测 `read -n1` 取到的是 ESC 而不是用户按的键），比乱码更严重，故不采用
  - 代价：输出更精简、不再显示百分比进度条，但每步仍有文字反馈

【问题修复】
- 修复「更新全部应用」在提示「没有更新。」之后长时间卡住
  - 根因：`flatpak update` 的流程是「先查更新 → 再刷新 appstream 元数据」。第二步要去 `dl.flathub.org` 拉约 10MB 的 appstream 数据，而该站当前连通率极低（实测 8 次试连只有 1 次成功），连接超时后还会重试 5 轮，于是卡在「正在为远程仓库 flathub 更新 appstream 数据」几分钟甚至更久

  - 现在没有更新时会明确显示「所有已安装应用均为最新版本，无需更新」，不再卡住

2026-10-26（v1.9.4）
【问题修复】
- 修复「GE-Proton 管理」安装时误报「解压失败（压缩包损坏或解压中断）」
  - 根因一（主因）：上游从 GE-Proton11-4 起改了产物命名，压缩包和包内顶层目录都带架构后缀（`GE-Proton11-11-x86_64.tar.gz`，解开是 `GE-Proton11-11-x86_64/`），而 release tag 仍是 `GE-Proton11-11`。旧代码解压后写死检查 `$STAGE_DIR/GE-Proton11-11`，找不到就当成解压失败——实际包是好的，`tar` 退出码也是 0，纯粹是判据写死了目录名
  - 根因二：镜像断流时返回 200 + 截断的包，curl 认为成功，`tar` 一路解到末尾才报 EOF，表现同样是「解压失败」。现在下载后先用文件大小 + sha512 校验，截断/损坏的包在解压前就被拦下
  - 现在解压后按「stage 里唯一的顶层目录」定位，并用 `<tag>` 与 `<tag>-*` 前缀兜底；安装目录名仍保持 `<tag>`（`GE-Proton11-11`），已装列表/卸载/Steam 显示名与旧版本一致
  - 下载失败提示更具体：区分「下载不完整（x/y 字节）」「sha512 校验失败」「压缩包结构异常」，不再一律报「解压失败」，便于判断是网络问题还是上游改名
  - 安装循环结束后补充清理下载临时目录，用户中途取消不再留 `/tmp/ge_proton_*` 残留

## ✨ 特性亮点

- **中英界面**：顶栏一键切换中文 / English，偏好自动保存，重启后保持
- **深色 / 浅色主题**：一键切换深色、浅色或跟随系统，偏好自动保存，重启后保持
- **智能系统检测**：自动识别单 / 双系统，部分功能（修复引导、互通盘）仅对双系统用户显示  
- **图形化引导管理**：支持 Clover 引导的安装、重装，并附带“引导文件配置”工具箱（主题、超时、默认系统等）  
- **双系统专属支持**：Clover 启动顺序修复、Windows–SteamOS 数据互通盘自动挂载  
- **一键软件管理**：涵盖办公、通讯、浏览器、云盘、音乐等常用应用（Flatpak / 脚本安装）  
- **深度性能优化**：虚拟内存调整（CryoByte33 方案 / 传统 Swap / ZRAM）、GE-Proton 兼容层管理、Steam 着色器与兼容数据缓存管理、Hosts 缓存清理  
- **游戏增强组件**：摇杆与扳机校准、LSFG‑VK / Framegen / Freedeck 插件、小黄鸭软件（Lossless Scaling）  
- **第三方游戏平台**：支持安装育碧（Ubisoft Connect）、Epic、战网（Battle.net）等游戏平台  
- **持续更新**：启动时自动检测更新，支持一键升级，无需手动下载
