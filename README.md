SteamDeck 工具箱
一个专为 SteamDeck 打造的一站式系统管理与增强工具，集成 系统优化、软件安装、网络加速、双系统支持、游戏增强 等 30 项实用功能，全面覆盖日常使用与进阶调校需求。工具箱会智能检测您的系统类型，并动态调整可用功能（如双系统用户才显示引导修复和互通盘配置）。无论您是初次使用还是资深玩家，都能快速找到所需工具，让 SteamDeck 更好用、更好玩。

主要功能
🔧 系统优化：国内源配置｜虚拟内存调整｜磁盘写入错误修复｜hosts 缓存清理｜管理员密码设置
📦 软件管理：一键安装 QQ、微信、WPS、Edge/Chrome 浏览器、百度网盘、QQ音乐等常用应用｜应用更新与卸载
🌐 网络工具：UU/迅游加速器插件｜ToMoon 网络优化｜AnyDesk｜ToDesk 远程协助
🔄 双系统支持：引导修复｜Windows-SteamOS 互通盘配置｜双系统维护（仅双系统用户可见）
🎮 游戏增强：摇杆校准｜插件商店/宝葫芦管理｜小黄鸭插件/软件｜Steam 缓存清理｜Decky-Framegen插件
📁 便捷工具：虚拟内存调整｜工具箱自更新｜已安装应用管理｜缓存清理

一键安装
在 Konsole 中执行以下命令即可安装：

bash
curl -L https://gitee.com/Zhucy2100/steamdeck_toolbox/raw/master/steamdeck_toolbox.sh -o /tmp/steamdeck_toolbox.sh && chmod +x /tmp/steamdeck_toolbox.sh && /tmp/steamdeck_toolbox.sh
